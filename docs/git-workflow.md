# Git workflow

Inspect status and preserve unrelated user changes. Keep changes scoped to the requested increment.
Do not stage, commit, push, tag, create a pull request, rewrite history or deploy unless requested.

Use small descriptive commits when authorized, for example `chore: define the Stock Radar MVP.`
For an explicitly requested message format, use the [commit message generator](commit-message-generator.md).
That guide produces text only and does not authorize staging or committing.
Never add secrets, real collected records, database volumes or private browser exports. Review the diff
and run applicable checks before proposing completion. No license is selected by this scaffold; do not
copy a reference project's license or publish a release under an assumed license.
